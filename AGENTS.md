# Infiniglyph project guidance

Read [the canonical world lore](docs/canonical_world_lore.txt) before designing
or changing NPCs, dialogue, bosses, world storytelling, stage transitions or
progression. This is the user's foundational narrative reference, preserved
verbatim from the supplied profile.

- Native inhabitants are autonomous artificial beings with individual motives
  and attitudes. Anti-human prejudice is cultural, not caused by the Bug.
- Human players are outsiders, without a predetermined chosen-hero role.
- The Infiniglyph is a curious, knowledgeable observer and the hidden final
  opponent. Its encounters use shared combat fundamentals, observable actions
  and fair adaptation rather than omniscient input reading.
- Treat the profile's unresolved questions as open. Obtain explicit design
  approval before establishing definitive answers to them.
- Fictional administrative abilities and Stage Glitches belong inside bounded
  game systems. They do not authorize host filesystem access or code execution.
- The lore establishes context, not a request to implement every system it
  describes. Follow the current user request's scope.

All menus, including Start/Settings and Select/View inventory, keep the world
simulation running. Capture local gameplay inputs without pausing the scene tree.
